    3. D02 代码轨（25min，有余力）。看 rag/llm/embedding_model.py 的 encode_queries / encode，以及 rag/nlp/search.py::hybrid_similarity。验收是能解释为什么查询用 query 编码、入库用 document 编码，说出 tkweight/vtweight 各是什么。
    4. 取舍：今天总量约 2.5h，补 D01 代码阅读优先于 D02 代码轨；D02 代码轨读不完可以顺延，D05 不动。

    知识点（要能自己讲出来，不是见过）¶

    1. 双塔结构：文档塔和查询塔为什么分开编码，而不是一个模型同时吃两边
    2. 对比学习目标：正样本、负样本怎么构造，loss 在拉近什么、推远什么
    3. 向量归一化：cosine / 内积 / L2 三者的等价条件（今天的核心公式）
    4. 维度与语义分辨率：512 维能表示多少种不同的意思，压到 64 维会丢什么
    5. 中文 tokenizer 的影响：jieba 分词和字级切分，对同一句话的向量差多少

    方法（计划指定：控制变量实验）¶

    同一批向量只改一件事：做一次归一化、一次不做，各检索一次，记录 Top-5 的差异。用差异反推公式，而不是先背公式再验证。

    验收标准（计划原话）¶

    1. 能解释为什么归一化后内积等于余弦
    2. 手写实现与库（faiss / sentence-transformers）结果 Top-10 重合 ≥ 9
