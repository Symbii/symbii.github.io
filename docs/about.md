# 关于本站

一个后端工程师的 RAG 自学记录。56 天，每天 1.5–2 小时，从 RAG 到底在解决什么问题，一路走到能自己写一个带检索、重排、引用的小系统。

## 这里写什么

每天的笔记里，概念怎么理解、推导怎么走、源码锚点在第几行、实验量到多少、哪里卡住。想错的地方也留着：笔记里有不少我一开始以为是 X、其实是 Y 的段落，这些比结论有用。数字都是自己跑出来的，不是抄的，跑法写在笔记里。

## 这里不写什么

工作里的东西不在这。文中出现的解析服务 A、检索服务 B 是脱敏代号，对应的是私有仓库，只能看到它们在学习链路里扮演哪一环。

## 关于论文译文

《RAG 原论文中英对照》是对 arXiv:2005.11401（Lewis et al., 2020）的逐段翻译，仅供个人学习。原文版权归原作者，引用请以 [arXiv 原文](https://arxiv.org/abs/2005.11401) 为准。译文里凡是 `📌 译注` 开头的内容都是译者自己补的，不是原文。

## 关于代码

练习代码是照着先自己写、写完再对答案的节奏来的，所以有些文件里留着写错又改的痕迹，那是故意的。
