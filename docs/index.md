## 这个站在学什么

从「RAG 到底在解决什么问题」开始，八环链路 → Embedding 与相似度 →
向量索引（HNSW）→ 词法检索（BM25）→ 重排 → 生成与引用 → 评测与误差分析，
最后落到一个能跑、能测、知道哪里会坏的小系统。

所有笔记都是当天现写的，有大量「这里我想错了」的记录——那部分比结论有用。
